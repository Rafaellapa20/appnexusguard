# Como usar no Antigravity

1. Cria uma pasta vazia (por exemplo NexusGuard-Android) e abre-a no Antigravity (File → Open Folder).
2. Copia AGENTS.md para a raiz dessa pasta. O Antigravity lê-o sozinho como regra fixa (logo, cores, princípios, limites do Android).
3. No Agent Manager, abre uma conversa nova:
   - modo **Planning**;
   - modelo: o mais forte disponível (Gemini 3 Pro ou Claude Sonnet/Opus).
4. Cola o texto de PROMPT-inicial.md.
5. Revê o Implementation Plan, comenta o que quiseres e aprova.
6. No fim de cada fase, vê o walkthrough e as screenshots e diz «avança para a fase 2», e por aí fora.

Precisas de ter o Android SDK e um emulador instalados (Android Studio). Se faltar algo, o agente diz-te o que instalar.
